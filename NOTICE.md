# Notices

Cadence borrows ideas from **instagram-agent-skill** by Jake Schincariol (https://github.com/Jakeschincariol/instagram-agent-skill, MIT License): the five-property hook panel, the caption-window preview, the humanizer passes (invisible characters, typography, stock-phrase swaps), the five-check human score, the swipe-file ranking and the profile rubric.

No code or word lists were copied from that repository. The implementation, the LinkedIn hook formulas, `lexicon.json`, the profile rubric and the thresholds were written for Cadence. Where the Instagram project is Instagram-specific (stories, 1080x1350 image files, reel formats, the hashtag cap), it was not carried over.

Cadence itself is for personal use. It uses LinkedIn's official API only.
